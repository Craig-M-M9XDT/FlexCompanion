# v0.6.5 development investigation: TX spectrum and current meters

## Observations
- v0.6.4 DAX IQ FFT is an **RX-side** stream. It is not a calibrated measurement of transmitted RF.
- Aether's localhost FCSP pan bridge may supply a radio-rendered panadapter frame while transmitting, if the source actually carries TX data. A successful RX pan frame does not prove TX availability.
- The display now labels whether frames came from RX or whether a live Aether pan frame was received during TX. This is a diagnostic step, **not a verified TX-spectrum solution**.
- Current/voltage conversion was corrected from raw/256 to raw/1024 to match FlexLib and Aether's VITA-49 description. Test against firmware/radio diagnostics.
- Added alternative PA current meter metadata names for compatibility; actual names and hardware support should be validated with `meter list`.
- FlexRadio's SMART-11281 response states the PA Current meter added to software for FLEX-8000 can be invalid for FLEX-6000. **Do not display an inferred amp reading** on hardware that lacks a supported current measurement.

## Before release
1. Test with RX and TX in DIGU, USB, LSB, AM, FM and CW where supported.
2. Capture spectrum stream identifiers and a non-sensitive meter-list response on FLEX-6600M and, if possible, FLEX-8000.
3. Verify RX returns instantly after PTT and no new stream/channel assignment disrupts SmartSDR.
4. Profile FFT CPU/time, GC allocations, redraw frequency, meter event coalescing and UDP packet loss on Windows and ARM64.
5. Verify battery/power/voltage/current readouts against an external instrument or known-good calibrated display when supported.
